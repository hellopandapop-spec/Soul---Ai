# Soul AI Starter Project

This is a starter Android app with local video playback and a basic Hindi text-to-speech test. It does not yet implement automatic English-to-Hindi video dubbing.

## Build on GitHub Actions

1. Upload the contents of this ZIP to the repository root, preserving the folder structure. Do not upload the ZIP file itself and do not flatten the folders.
2. Confirm `app/build.gradle.kts`, `app/src/main/AndroidManifest.xml`, and `settings.gradle.kts` are visible at the paths shown in this ZIP.
3. Commit to the `main` branch, then open the Actions tab and run **Build Soul AI APK** if it has not started automatically.
4. When the run succeeds, download `Soul-AI-debug-APK` from Artifacts. Extract the downloaded artifact ZIP to find `app-debug.apk`.
